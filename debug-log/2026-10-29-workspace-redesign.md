# 2026-10-29 · Quiet Workspace 整体界面改版

## 用户反馈

整个界面显得逼夹，希望重新设计，而不是仅微调某个组件。

## 原因与设计处理

- 原首页叠加岛屿风基础样式、Classic／macOS 两套布局、下拉子导航、Dock、悬浮装饰与认证徽章，视觉入口过多。
- 工具入口集中在侧栏下拉，任务在窄屏仍按固定最小宽度横排；模块的正文、边框、操作与装饰缺乏一致层级。
- 首页 viewport 禁止缩放；部分状态文字对比偏低。

改为单一 Quiet Workspace：米白／鼠尾草色、固定侧栏、页内分区、独立滚动内容区与专注模式。九个工具改为分类／搜索目录，独立操作页附三步说明；任务在手机与窄平板自然纵排；Agnes 技术参数改为可展开设置；分析帮助不再强制展开；备忘与留言限制阅读宽度。

当前样式入口：`web/assets/workspace.css`。布局交互：`web/assets/workspace.js`。设计约定：`docs/UI-DESIGN.md`。旧布局资源保留，但不再由首页加载，用户既有 localStorage 数据不主动删除。

## 改版中发现并修复的问题

1. **移动菜单显式开关方向相反**
   - 旧 `toggleMobileMenu(false)` 会进入打开分支，点击导航后可能不能关闭侧栏。
   - 改为参数直接代表目标打开状态；同步 `aria-expanded`、遮罩及隐藏导航的 `inert`。

2. **任务改变后进度与分区状态不同步**
   - 原局部重绘复用旧 greeting，进度可能滞后；日历／历史选日仅更改内容状态，页内导航仍停在旧分区。
   - greeting 每次依照任务项目重新计算完成数；选日后同步任务分区。新增任务明确携带 `is_custom`，保证删除入口存在。

3. **浅色辅助文字不可读**
   - 初稿 axe-core 检查发现侧栏、工具说明、状态和小标签的对比度不足。
   - 保留浅背景与细边框，统一提高功能文字对比；完成任务以删除线／浅背景区分，不再降低整个卡片透明度。补齐图片格式选择及压缩质量的可访问名称。

4. **浏览器缓存与手机测试陷阱**
   - `navigate` 使用 URL 导航时的 `ignoreCache` 不能代替明确的 `type: reload`；曾短暂混用新 HTML 与旧 Agnes 脚本，导致高级设置测试失败。
   - 统一更新首页资源版本，测试用 `reload + ignoreCache`。
   - 桌面窗口 resize 到 320／390px 会被 Chrome 最小窗口宽度限制在 500px；改用 viewport emulation，并核对实际 `innerWidth`。
   - 切换 mobile emulation 可能重载页面，需在重载时重新注入隔离测试 fixture，不能把无数据错误页当成任务页面验收。

## 验证

- `node --check web/assets/*.js`（逐文件执行）通过；`git diff --check` 通过。
- 隔离浏览器中拦截全部 `/v1/` 请求，无真实任务写入、邮件操作或付费生成。
- **41 项互动作业通过**：六页导航、任务推进／进度／新增／删除入口、工具筛选搜索、九个工具操作页面、三个 Agnes 标签、五种配色、专注模式、日历选日、键盘锁屏／解锁等。
- 移动抽屉打开／关闭、ARIA 状态、主题弹层与隐藏焦点另外检查通过。
- **7 个实际 viewport × 20 个场景 = 140 项响应式检查通过**：320、375、390、768、1024、1440、1920px；六页、日历／总结、九个工具、Agnes 展开参数均无内容区水平溢出。
- axe-core 4.10.3：默认配色下六个入口页面及九个工具页面，所运行的 `wcag2a`／`wcag2aa`／`wcag21aa` 自动规则未报告违规。测试时禁用动画，避免过渡中的低透明度导致误判；这不等于完整无障碍人工认证。
- 本地截图与测试脚本位于忽略目录 `.pi/design-review/`，模拟资料未放入 `web/`。

## 边界

初次本地改版验收没有修改后端、业务指令或生产数据；Git 推送与正式发布验收另记于下方。静态 localhost 不在生产 API 的 CORS 白名单时，会显示可重试的连接提示；浏览器 UI 验收使用隔离 fixture，不将本地 CORS 错误视为线上故障。实际邮件、文件转换与 Agnes 上游服务不在本次端到端联调范围。
