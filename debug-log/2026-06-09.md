# 问题 1：工作面板一直显示"加载中"，API 无请求

## 现象
- 点击工作面板 → 今日任务 → 一直显示"加载中"
- DevTools Console: `dashboard.js:228 Uncaught SyntaxError: Invalid or unexpected token`
- Network: 没有任何 API 请求

## 根因
dashboard.js 第 228 行 `renderSection` 函数中拼接 SVG 时，三元表达式末尾多了一个多余的 `'`：
```
' : '')';
```
应为：
```
' : '');
```
第 228 行共 646 字符，多余的 `'` 在位置 645（0-indexed），导致整行结尾变为 `' : '')';`，
JavaScript 解析器认为 `)` 后面还有个未闭合的单引号字符串，SyntaxError 导致整个 dashboard.js
脚本无法执行。

dashboard.js 一旦解析失败：
- `dashState` 变量未定义
- `loadDashboard` 函数未定义
- `initDashboard` 检查 `typeof loadDashboard !== 'function'` 为 true → 直接 return
- 面板保留初始 HTML "加载中…"，从未发出 API 请求

## 修复
- 删除多余的 `'`，结尾改为 `' : '');`

## 附加修复
1. 缓存彻底解决：index.html 中所有 script 标签加 `?v=2` 参数
2. 请求超时：fetch 加入 12s AbortSignal.timeout()，超时后显示"请求超时"
3. 配置检测：dashUrl() 返回空时显示"配置错误：API 地址未设置"
4. 诊断日志：initDashboard 失败时 console.warn 输出 `dash-init: ...` 提示
5. CSP：connect-src 加了 cdn.jsdelivr.net（pdf-lib source map 需要）

# 问题 2：勾选任务后备注丢失

## 现象
- 勾选 checkbox 后，之前保存的备注消失

## 根因
`saveChecklist()` 保存成功后调用 `renderActiveTabOnly()` 全量重新渲染 DOM，
销毁所有 textarea（含未保存的草稿），重新创建时因 in-memory 数据中 note 字段
在某些时序下为空，导致备注丢失。

## 修复
- saveChecklist 改为 300ms 防抖（debounce）
- 保存成功后不再全量重绘，改为 `updateProgressRing()` 原地更新：
  - 进度圈 SVG 的 stroke-dashoffset
  - 每个任务的 checkbox 状态和 textarea 值
- 服务端响应 merge 到内存状态，不重新创建 DOM
