四、工作面板 新版

点击顶部 「任务」 按钮进入。工作面板分三个标签页：

4.1 今日任务

  • 顶部问候卡片显示当前日期、周几、任务进度环
  • 按上午 / 下午分两组，每组以彩色圆点标识（紫色=上午，蓝色=下午）
  • 每条任务左侧有复选框，点击打勾表示完成
  • 点击任务右下角的 📝 按钮可添加/编辑备注
  • 底部 「总结今天任务完成」 按钮：AI 自动生成当天完成情况总结并保存

4.2 工作日历

  • 顶部显示当前月份和年，左右箭头可切换月份
  • 数字下方的圆点标记表示该天有历史任务数据
  • 点击日期可查看当天的任务完成情况

4.3 每日总结

  • 按月显示已保存的 AI 每日总结
  • 每条总结包含日期和 AI 生成的工作回顾内容

八、常见问题

❓ 页面打不开怎么办？
确认网络正常。如持续无法访问，联系管理员。
❓ 工作面板（任务）加载不出来？
检查 API 地址和令牌是否正确。工作面板需要从服务器获取任务模版数据。
❓ 任务打勾后，下次打开还在吗？
任务状态保存在服务器数据库，跨设备同步。
❓ 上传文件后没有反应？
检查文件格式（仅支持 .xlsx / .xls / .csv），文件不能超过 20MB，并确认 API 地址和访问令牌填写正确。
❓ 浏览器通知没弹出？
确认设置中已开启「浏览器通知」，并在浏览器地址栏左侧 🔒 处检查该网站的通知权限是否被屏蔽。
❓ AI 回答不准确？
AI 的知识截止于训练数据时间，无法直接访问你的 SharePoint/邮件数据。具体的订单数据需要你上传 Excel 文件进行分析。
❓ 如何切换 AI 模型？
联系管理员在服务器配置中修改模型即可。
❓ 如何联系支持？
如有问题或需要调整配置，请联系 IT 管理员。
